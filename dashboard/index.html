The model

A calibrated ensemble, anchored to the market

closing odds + line movement+ Elo · xG-form · squad value · form → LightGBM · RandomForest · HistGB · Logistic → calibrate (sigmoid) → blend toward the market → pick the winner

~17 features, chosen deliberately — a small set matched a 300-feature version, so extra features only added noise. Trained through 2023/24, tuned on 2024/25, and evaluated once on 2025/26. The new signals we added — how the odds moved before kickoff and real expected goals (xG) — carried genuine information but added almost nothing beyond the odds, which already reflect them.

What we learned

Four honest findings

ceiling The market is the ceiling

The betting odds already reflect everything public — form, injuries, spending. No model we built on public data beat the closing odds, mostly because draws are close to unpredictable. It’s a structural limit, not a gap we could feature-engineer past.

leakage caught Understat’s “forecast” is a retrodiction

Understat’s per-match forecast correlates 0.96 with that same match’s realised xG — it’s computed after the fact. Using it inflated accuracy to 0.52. We found it and dropped it. Rigor over a fake number.

tested, no lift Fixture congestion doesn’t help

We scraped all-competition fixtures (FA Cup, EFL Cup, UCL, UEL, UECL) to build true rest-day and midweek-load features. They don’t improve prediction — congestion is confounded with team quality the market already captures.

reality check Flipping the picks doesn’t help

A tempting shortcut: can you “flip” a mediocre model to make it good? No — that’s binary thinking. When we reversed a Home/Away-only model, its correct calls became misses and accuracy fell from 0.50 to 0.23. Worth ruling out.
